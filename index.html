Pour le déploiement, voici les deux étapes :

1. Pousser sur GitHub

bash
bash
# Depuis le dossier du site
cd ~/. openclaw/workspace/biographie-site

# Initialiser le repo git

gh repo create biographie-site --public --source=. --remote=origin --push

Ça crée le repo et pousse le code en une commande.

2. Déployer sur Cloudflare Pages

Option A — Dashboard (le plus simple) :

  3. 3.Configuration :

  4. 4.Clique Save and Deploy
  5. 5.Ton site est live en ~30 secondes à biographie-site.pages.dev
